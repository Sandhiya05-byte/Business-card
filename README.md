# 💙 Digital Business Card

A simple and modern digital business card built using **HTML** and **CSS**.  
This project showcases a personal profile with a clean design, circular profile image, custom Google Fonts, and responsive styling.

## ✨ Features

- 🎨 Modern and aesthetic UI
- 🖼️ Circular profile picture
- 🔤 Google Fonts integration
- 🌈 Soft pastel color palette
- 📱 Clean and responsive layout
- ✨ Hover effects and smooth animations

## 🚀 Technologies Used

- HTML5
- CSS3
- Google Fonts
